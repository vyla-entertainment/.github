# Vyla Entertainment

**A unified entertainment ecosystem for streaming and game discovery.**  
Personal use · Multi-source aggregation · Edge-powered APIs

</div>

---

Vyla Entertainment is an integrated media system that connects multiple streaming providers and game databases through a single interface. It centralizes movies, TV shows, and games by routing requests across distributed APIs and metadata sources.

It is designed for a mobile-first experience with a unified API layer that delivers fast access to content without complex configuration.

> [!NOTE]
> Vyla Entertainment is intended for **personal and experimental use only.**  
> Users are responsible for how content is accessed and must comply with applicable laws and third-party terms of service.

---

## Features

| Capability | Description |
|---|---|
| Multi-Source Streaming | Aggregates multiple providers for movies and TV via TMDB-based routing |
| Game Discovery | Browsing system for games with structured metadata and genre filtering |
| Media Proxying | Handles stream delivery with CORS handling and URL rewriting |
| Secure Token Flow | Session-based request validation for controlled access |
| Personalized UI | Themed interface with responsive mobile-first design |

---

## Ecosystem Components

- **Vyla API** — Backend API layer for media routing and content resolution  
- **Vyla Games** — Game discovery and metadata engine  
- **Vyla Interface** — Secure request and session handling layer  
- **Vyla Web** — Main frontend for unified media access
