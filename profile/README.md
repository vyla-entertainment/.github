# Vyla Entertainment

**A unified entertainment ecosystem for streaming and media discovery.**  
Personal use · Multi-source aggregation · Edge-powered APIs

</div>

---

Vyla Entertainment is an integrated media system that connects multiple streaming providers through a single interface. It centralizes movies and TV shows by routing requests across distributed APIs and metadata sources.

It is designed for a mobile-first experience with a unified API layer that delivers fast access to content without complex configuration.

> [!NOTE]
> Vyla Entertainment is intended for **personal and experimental use only.**  
> Users are responsible for how content is accessed and must comply with applicable laws and third-party terms of service.

---

## Features

| Capability | Description |
|---|---|
| Multi-Source Streaming | Aggregates multiple providers for movies and TV via TMDB-based routing |
| Media Proxying | Handles stream delivery with CORS handling and URL rewriting |

---

## Ecosystem Components

- **Vyla API** — Backend API layer for media routing and content resolution  
- **Vyla Player** — Main player frontend for unified media access
- **Vyla Cli-Player** - Fun frontend developement using the stream API.
